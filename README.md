# Predicting Developers' Salaries

## Project Overview
This project aims to predict developers' yearly salaries using Python and Machine Learning.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Model
Linear Regression

## Evaluation
R-squared (R²) and Mean Absolute Error (MAE)

## Project Goal
To understand salary patterns and build a beginner-friendly salary prediction model.
